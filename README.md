## Коллекция игр

Наш проект включает **6 увлекательных мини-игр**, каждая из которых готова к использованию:

* **«Угадай число»** — проверьте свою интуицию
* **«Простая арифметика»** — тренируйте математические навыки
* **«Переверни текст»** — экспериментируйте с текстом
* **«Камень, ножницы, бумага»** — классический геймплей против компьютера
* **«Викторина»** — отвечайте на интересные вопросы
* **«Генератор цветов»** — создавайте уникальные цветовые решения

## Технологии разработки

В создании проекта использованы современные технологии:

* **JavaScript** — интерактивность и логика игр
* **HTML5** — базовая структура страниц
* **CSS/SASS** — стилизацию и оформление
* **БЭМ методология** — организация кода
* **Git** — система контроля версий
